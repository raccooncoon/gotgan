# 지식 신고

작업을 하다가 다음 중 하나를 만나면 신고를 남긴다.

- **없음(missing)**: 작업에 필요한 규칙이나 절차를 저장소의 문서와 지식 어디에서도 찾지 못했다.
- **틀림(wrong)**: 문서나 지식에 적힌 내용이 실제 코드나 동작과 다르다.
- **낡음(stale)**: 적힌 내용이 폐지되었거나 더 새로운 내용과 어긋난다.

## 규칙

- 지식 파일과 대상 저장소의 문서를 **고치지 않는다.** 신고만 한다.
- 찾지 못한 것을 추측으로 채우지 않는다. 작업 결과에는 "근거 없음"이라고 적고 신고한다.
- 신고 하나에 주제 하나만 담는다.
- 비밀 값, 접속 정보, 긴 코드 인용을 넣지 않는다.

## 형식

실험을 진행하는 쪽이 알려 준 신고 폴더에 파일 하나를 만든다. 파일 이름은 `F-<과제ID>-<회차>-<순번>.md`다(예: `F-T-01-r0-1.md`). 파일을 쓸 수 없는 환경이면 같은 형식으로 답변 끝에 적는다.

```markdown
---
kind: missing            # missing | wrong | stale
topic: '한 줄 주제'        # 값은 작은따옴표로 감싼다. 값 안의 작은따옴표는 두 번 쓴다
task: T-01
round: r0                 # 실험을 진행하는 쪽이 알려 준 회차
by: <에이전트 이름>/<모델>
at: "2026-11-27T05:00:00Z"
status: open
where: '관련 파일 경로 (알면)'
---

무엇을 하려다 막혔는지, 어디를 찾아봤는지, 무엇이 달랐는지 적는다.

제안: 올바른 내용을 안다면 근거와 함께 적는다. 모르면 비워 둔다.
```

이미 처리된 신고와 같은 주제를 다시 신고하게 되면 머리말에 `repeat_of: <이전 신고 파일 이름>`을 적는다.
